# ModelTMSCoil

Generate a TMS coil geometry with current sources to include in TMS modeling pipelines.

**Detailed Description**

The ModelTMSCoil module will use a set of parameters from the module UI (or module state) to generate a mesh with field data to represent a TMS coil in a TMS modeling pipeline. This module is designed to work with the [SolveBiotSavart](SolveBiotSavart.md) module where the current sources of the coil will be used to estimate the magnetic field through a target domain.


Module parameters used to generate the TMS coil geometry and field data are:
 - Model Type: Type of output geometry and current source representation.  Options are: Thin Circular Wires, Thin Spiral Wires, Magnetic Dipoles (see descriptions below).
 - Coil Shape: Shape of the coil: O-shape (one wing), 8-shape (two wings). 
 - Current Change (dI/dt) [A/µs]: Time-derivative of the current pulse in the TMS coil. 
 - Windings: Number of windings per loop of the coil. The total number of windings in a wing is `[Windings] x [Stack]`.
 - Wing Angle: Angle between the two wings of an 8-shaped coil.  
 - Radius Inner [mm]: Inner radius of each loop of the coil.
 - Radius Outer [mm]: Outer radius of each loop of the coil.
 - Outer Distance [mm]: Distance between the outer edges of the two wings of an 8-shaped coil.
 - Stack: Number of loops in one wing of the coil. Total number of windings in a wing is `[Windings] * [Stack]`.  
 - Stack Step [mm]: Distance between the loops in a stack. Height of the wing will be `[Stack Step] x ([Stack] - 1])`.
 - Level of Detail: Refers to the resolution of the output mesh.  Higher detail level will produce meshes with more points and edges.
 

The output of the module will be a SCIRun Field **Mesh** with the geometry and field data representing the TMS coil.  The mesh and data type will depend on the Model Type.  
 - Circle and Spiral types will output a curvilinear mesh with nodes and edges.  The scalar data on the nodes represents the current sources (dI/dt) [A/s]. Note this is not the same units as the input current.   
 - The Magnetic Dipole type will produce a point cloud mesh  with vector data indicating the magnetic moment for each loop of the coil.  There will be one node per loop (max of two) located at the center of the loop, and the vector is the magnetic moment generated by the current through the coil.
